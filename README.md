# 🚖 The Driver Pro - Mobile PWA App

ระบบติดตั้ง Web App **The Driver Pro** บนมือถือสำหรับคนขับและเจ้าของร้าน ทั้ง **Android** และ **iPhone (iOS)**

---

## 📁 ไฟล์ทั้งหมดในโฟลเดอร์นี้
* `index.html` : หน้า PWA Wrapper พร้อมระบบ Splash Screen และระบบตรวจจับการติดตั้ง
* `manifest.json` : การตั้งค่า Web App Manifest สำหรับติดตั้งแบบ Native App
* `sw.js` : Service Worker แคชไฟล์ระบบให้โหลดได้รวดเร็ว
* `apple-touch-icon.png` : ไอคอนสำหรับ iPhone / iPad (180x180)
* `icon-192.png` : ไอคอนสำหรับมือถือ Android (192x192)
* `icon-512.png` : ไอคอนขนาดใหญ่สำหรับหน้า Splash Screen (512x512)
* `favicon.png` : ไอคอนแท็บเบราว์เซอร์ (64x64)

---

## 🚀 ขั้นตอนการนำขึ้น GitHub Pages (ทำเพียงครั้งเดียว 2 นาที)

### ขั้นที่ 1: สร้าง Repository บน GitHub
1. เข้าเว็บ **[GitHub.com](https://github.com/)** แล้วเข้าสู่ระบบ
2. กดปุ่ม **`+`** ที่มุมขวาบน ➔ เลือก **New repository**
3. ตั้งชื่อ Repository เช่น `driverpro` หรือ `the-driver-pro`
4. เลือกเป็น **Public** (เพื่อให้ใช้ GitHub Pages ฟรีได้)
5. กดปุ่มเขียว **Create repository**

### ขั้นที่ 2: อัปโหลดไฟล์ทั้งหมด
1. ในหน้า Repository ที่เพิ่งสร้าง ให้กดลิงก์ **`uploading an existing file`**
2. ลากไฟล์ **ทั้งหมดในโฟลเดอร์ `GitHub_PWA` นี้** (ทั้ง 7 ไฟล์) เข้าไปวางในหน้าต่างเบราว์เซอร์
3. รอไฟล์อัปโหลดเสร็จ จากนั้นกดปุ่มเขียว **Commit changes**

### ขั้นที่ 3: เปิดใช้งาน GitHub Pages
1. ที่เมนูด้านบนของ Repository ให้กดไปที่ **Settings** (รูปฟันเฟือง)
2. แถบเมนูด้านซ้าย เลือกหัวข้อ **Pages**
3. ตรงหัวข้อ **Build and deployment** ➔ **Branch**:
   * เปลี่ยนจาก `None` เป็น **`main`**
   * โฟลเดอร์เลือกเป็น **`/(root)`**
   * กดปุ่ม **Save**
4. รอระบบประมวลผลประมาณ 1-2 นาที เมื่อรีเฟรชหน้าจะปรากฏข้อความ:
   > **Your site is live at `https://<ชื่อยูสเซอร์ของคุณ>.github.io/<ชื่อโปรเจกต์>/`**

## 📱 วิธีให้คนขับติดตั้งลงบนมือถือ

ส่งลิงก์ GitHub Pages ที่ได้จากขั้นตอนที่ 3 ให้คนขับเปิดบนมือถือ:

### 🤖 สำหรับมือถือ Android (ผ่าน Google Chrome)
1. เปิดลิงก์ผ่านแอป **Chrome**
2. หน้าเว็บจะแสดงแถบด้านล่าง **"ติดตั้งแอป The Driver Pro"** โดยอัตโนมัติ
3. กดปุ่ม **"ติดตั้งแอป"** (หรือแตะจุด 3 จุดมุมขวาบน ➔ เลือก **"ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"**)
4. ไอคอนแอป **The Driver Pro** จะไปปรากฏบนหน้าจอมือถือเหมือนแอปทั่วไปจาก Play Store เปิดใช้งานแบบเต็มจอ ไม่มีแถบ URL กวนใจ!

### 🍏 สำหรับมือถือ iPhone (iOS) (ผ่าน Safari)
1. เปิดลิงก์ผ่านแอป **Safari** (สำคัญ: ต้องใช้ Safari เท่านั้น)
2. แตะปุ่ม **แชร์ (Share)** รูปกล่องสี่เหลี่ยมมีลูกศรชี้ขึ้น `[↑]` ที่แถบด้านล่างของหน้าจอ
3. เลื่อนลงมาแตะที่เมนู **"เพิ่มไปยังหน้าจอโฮม"** *(Add to Home Screen)*
4. แตะ **"เพิ่ม"** *(Add)* ที่มุมขวาบน
5. ไอคอนแอปสวยคมชัดจะไปอยู่บนหน้าจอโฮมของ iPhone ทันที เข้าใช้งานได้ลื่นไหลแบบ Standalone App!
